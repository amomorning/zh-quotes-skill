# 中文引号 —— 上下文排版 Skill

> **English:** This skill fixes a typography bug common in Chinese text generated by LLMs: Chinese quotation marks（""）breaking code syntax. It enforces context-aware quote selection — ASCII quotes inside code, Chinese quotes in prose. See the rules table below.

## 安装

### Claude Code（推荐）

在项目根目录或 `~/.claude/` 下运行：

```bash
claude skill add zh-quotes
```

或手动安装：

```bash
git clone https://github.com/amomorning/zh-quotes-skill.git ~/.claude/skills/zh-quotes
```

安装后在项目 `.claude/settings.json` 中确认 skill 已注册：

```json
{
  "skills": ["zh-quotes"]
}
```

### 手动安装（其他 AI 工具）

将 `SKILL.md` 内容复制到你的 system prompt 或规则文件中即可。本 skill 不依赖任何运行时环境，核心逻辑全部在 `SKILL.md` 中。

## 问题

LLM 生成中英混合内容时，经常出现以下错误：

- 中文引号（""）出现在 Python/JSON/Typst 语法内部 → **解析报错**
- ASCII 引号出现在中文正文里 → **排版错误**
- 嵌套上下文（Markdown → 代码 → 中文字符串 → 中文引号）→ **上下文混淆**

## 解决方案

核心原则：**排版跟随语法上下文，而非自然语言。**

优先级：

1. 编程语言语法
2. 标记语言语法
3. 数据序列化语法
4. 自然语言排版规范

## 激活条件

当输出同时包含中文字符与 ASCII 语法符号时自动激活，或在处理以下格式时激活：Typst、Markdown 代码块、JSON/YAML/TOML、Shell 命令、正则表达式、HTML/XML、LaTeX。

## 规则速查

| 上下文 | 引号风格 |
|---|---|
| 纯中文正文 | “” ‘’ |
| 代码语法（Python、Rust 等） | `""` `''` |
| 代码字符串内的中文引用 | 外层用 ASCII，内层用 “” |
| Typst 语法 | `""` |
| JSON / YAML / TOML | `""` |
| Shell / 正则 / HTML / XML | `""` `''` |
| Markdown 正文（代码外） | “” ‘’ |
| Markdown 代码行/代码块 | 保持原始语法不变 |

## 示例

正确 —— 中文正文：
```
“生成设计”是一种方法论。
```

正确 —— Python 字符串中的中文引用：
```python
message = "用户点击“生成”按钮"
```

正确 —— 嵌套 Markdown → Python → 中文：
````md
系统提示“生成完成”后：

```python
message = "系统提示：“生成完成”"
```
````

错误 —— 代码语法中使用了中文引号：
```python
text = “生成设计”  # 解析报错
```
